## §2 — [MAJOR] RTL не переворачивает числа (ar)
1. Локаль ar, `#/reports`: score-pill читается **«2.7 / 5»** слева направо
   (не «5 / 2.7»). Инспектор: у элемента `direction:ltr` + `unicode-bidi:isolate`.
2. Бэнды отчётов: «≥ 4.5» и «< 3.5» — знак СЛЕВА от числа в визуальном
   порядке (не «4.5 ≤»).
3. Дашборд: «/ 5.0» в юнит-бейдже — LTR-изоляция.
4. ar-словарь: evaluateSub/scorePh/notesPh/auto.eta формулируют диапазоны
   словами («من 0 إلى 5») — читать глазами, порядок слов естественный.
5. Регресс: остальной RTL-интерфейс (меню, таблицы) зеркалится как прежде.

## §3 — [MAJOR] CV markdown остаётся LTR
1. Локаль ar, `#/cv`: textarea — `dir="ltr"`: строка «# Сергей» рендерится
   «# Сергей» (решётка слева), маркеры «- **Email:**» на месте.
2. LTR-превью рядом: не right-aligned, пунктуация не прыгает по строкам.
3. Заголовок/кнопки вокруг textarea — RTL (арабский), как прежде.
