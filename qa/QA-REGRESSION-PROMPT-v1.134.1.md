## §1 — What changed (3 fixes + 1 security)

1. **`successfactors` mid-scan partials** — the RMK pagination loop had no `try/catch` (regression from the v1.134.0 dead-board-throw port): a page-2+ failure after page-1 success threw and dropped the partials, and a `404` on an out-of-range `startrow` could quarantine a **live** tenant as dead. Now mirrors `phenom`/`radancy`: page-0 outage throws (dead board), later-page failure keeps partials.
2. **`#/scan` filter chips keyboard-operable (WCAG 2.1.1)** — the stack/level/dynamic-keyword facet chips and the "clear" chip were `<span onClick>` with no `tabindex`/role; now `role="button"`, `tabindex="0"`, `aria-pressed`, Enter/Space activation.
3. **3 hardcoded English strings localized** — `#/scan` trust tooltip (`scan.trustTip`), `#/scan` reloc column header (`scan.col.reloc`) — 2 new keys ×17 — and `#/dashboard` score header (reuse of `track.col.score`). Source-static guard locks them.
4. **Security:** `fast-uri` 3.1.4→3.1.5 in `site/package-lock.json` (Dependabot GHSA — host confusion via backslash authority; transitive dev-only dep of the Astro toolchain).

## §2 — Manual browser pass

1. **`#/scan` keyboard a11y** — `Tab` into the facet-chip stack (stack/level/dynamic keyword chips + "clear"); each chip is focusable, shows a focus ring, and toggles on **Enter** and **Space**; a screen reader announces `button` + pressed state. Mouse click still toggles.
2. **`#/scan` localized strings** — switch language (e.g. `ru`, `ja`, `ar`): the trust-badge tooltip and the relocation column header are now in that language (were English before). `ar` stays RTL-correct.
3. **`#/dashboard` score header** — the score column header is localized (reuses the tracker `track.col.score` string).
4. **`#/scan` results still render** — run a scan; a source whose later page fails no longer wipes the already-scraped rows (successfactors partials preserved); a genuinely dead board still surfaces a failure on `#/portals`.
5. **cvstart.org** (after Pages redeploy) — version badge reads **1.134.1**; the `/changelog/` page shows the `[1.134.1]` entry in every locale.

## §3 — Contract & security invariants

- **No new routes / no new writes.** All three fixes are client-side (chips, i18n) or source-internal (successfactors control flow). Scanners still run in-process.
- **Dead-board contract preserved:** a source THROWS only when nothing resolved; a partial scan is kept (proof-of-life). `successfactors` now honors this (was violating it on page-N failure).
- **i18n parity:** `scan.trustTip` + `scan.col.reloc` exist in all **17** locale dicts; snapshot `tests/fixtures/i18n-dict.snapshot.json` regenerated (1161 keys). No bare `'Trust '` / `'Reloc'` / `'Score'` literals remain in `scan-results.js` / `dashboard.js`.
- **CSP unchanged:** chips use `addEventListener` (`onClick`/`onKeydown` via `UI.el`), no inline handlers, no new `innerHTML`.
- **Site changelog mirrors** (`site/src/content/changelog/<L>.md`) are build-generated by `sync-assets.mjs` — all 17 must match the root `CHANGELOG.<L>.md` after the fan-out (re-run the site build **after** every locale is finalized, else a mid-fan-out build snapshots a partial set).
