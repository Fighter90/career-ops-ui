## Top 5 (by user impact)

1. **NF-1 (HIGH)** — Doctor / Verify-pipeline modals dump raw Node.js crash traces (full paths, `MODULE_NOT_FOUND`, Node version) instead of a diagnosis, in the exact tool meant to help a stuck user. Root cause: `runner.mjs::runNodeScript` → `routes/runners.mjs` ships raw `stderr` verbatim; client renders it in a `<pre>`. Same path serves doctor/verify/normalize/dedup/merge/sync-check/reconcile.
2. **NF-2 (HIGH)** — On `#/health`, the one REQUIRED card that FAILs (`modes/oferta.md`) is the *only* card with no body text and no "Fix →" — while optional cards (profile, API keys) get full guidance.
3. **NF-3 (HIGH)** — The boot-time "Setup issue: modes/oferta.md" toast is `position:fixed` ~10s and sits directly over the `#/scan` Source `<select>` (elementFromPoint returns the toast), clips the `#/apply` checklist tail, and covers the `#/health` Playwright card. (DES-1 only cleared toast-vs-FAB, not toast-vs-in-page-controls.)
4. **NF-4 (HIGH)** — On `#/help`, the docs FAB overlaps the right ~half of the "↑ Back to top" button's hit target; `elementFromPoint` inside the Back button returns the FAB, so half the button silently opens the chat instead.
5. **NF-5 (HIGH)** — The documented v1.117 "knock-out pre-scan" does nothing in the web-ui: a JD with 3 blatant disqualifiers yields the identical boilerplate line as an empty JD. Confirmed static string at `prompts.mjs:370` — it's an instruction to the AI CLI, not a computed check.

## Promise-fidelity ledger
- `#/apply` knock-out (NF-5) — **under-delivers** (boilerplate, not a check).
- `#/health` doctor/verify (NF-1) — **under-delivers** (crash dump, not a diagnosis).
- Error-copy doctrine ("never a bare stack/endpoint") — violated by NF-1, NF-6 (and informationally NF-2/NF-3).
- `#/stats` subtitle (NF-11) — minor omission.
- **No** divergence found in scoring thresholds, mode vocabulary, or the "OR" provider-cascade model — those match the docs honestly.

## What's genuinely good
Trust copy is specific and consistent (Memory / Usage / Orientation / CV Studio / Two-pager scope statements) · empty states teach the next step almost everywhere · the manual-prompt "OR" story is legible on every live-capable page · Arabic RTL mirrors thoroughly (sidebar, FAB→bottom-left, arrows flip, no LTR chrome leak) · 404 is clean · previously-shipped fixes (auto stepper, hero CTA, ⌘K hint, scan Stop-when-idle) all hold · placeholder-as-example teaching device · CV Studio's 5 tools each carry a one-line scope statement.
