## [1.259.0] — 2026-10-25

**ஏஜெண்ட் கூட்டத்தின் இரண்டாவது ரயில், ஆறு திருத்தங்கள்: அறிக்கை தேதிகள் server-பக்கத்திலேயே பின் செய்யப்படுகின்றன, வரைபட geocoder cache செய்து RU நகரங்களைப் படிக்கிறது, help ×18 மொழிபெயர்க்கப்பட்ட பொத்தான் labels-ஐச் சுட்டுகிறது, UI வாக்கியங்கள் மொழிகளைக் கலப்பதை நிறுத்துகின்றன, சம்பள ஒப்பீடுகள் server-பக்கத்திலேயே கணக்கிடப்படுகின்றன — மேலும் JS bundle precompressed-ஆக வழங்கப்படுகிறது (cold load 3.1 MB → 598 KB).**

### சரி செய்யப்பட்டது

- **புனையப்பட்ட அறிக்கை தேதிகள் (CAR-101)**: மதிப்பீட்டு prompt இப்போது இன்றைய தேதியை server-பக்கத்திலேயே பின் செய்கிறது («the **Date:** field MUST be exactly <date> — copy verbatim; never invent»), மேலும் `fixReportDate` எந்தவொரு acceptance site-இலும் (Anthropic branch, Gemini subprocess, OpenAI-இசைவான tail, /api/deep, auto-pipeline) தவறி நழுவிய தேதியை இன்றைக்கு மறுஎழுத்தாக்கம் செய்கிறது — எச்சரிக்கை + activity பதிவுடன்; இது ஒரு திருத்தமே தவிர நிராகரிப்பு அல்ல. 349/789 ப்ரொடக்ஷன் அறிக்கைகள் புனையப்பட்ட தேதிகளைக் கொண்டிருந்தன; புதியவற்றால் இயலாது.
- **வரைபட geocoding (CAR-105)**: hh.ru/Habr வரிசைகளின் சிரிலிக் நகர சரங்கள் இப்போது geocoder-ஐ அடைகின்றன; நிரந்தரமான எல்லைக்குட்பட்ட cache (`data/geocode-cache.json`, withFileLock) மூலம் முடிவு செய்யப்பட்ட ஒரு நகரம் வழங்குநரை இருமுறை தொடுவதில்லை; geocode அழைப்புகள் request-க்கு பட்ஜெட் செய்யப்படுகின்றன, எனவே வரைபடம் 13.9 s தடைபடுவதற்குப் பதிலாகப் படிப்படியாக நிரம்புகிறது.
- **கலப்பு-மொழி UI (CAR-108)**: 19 dicts-இல் 17-இல் (85 மதிப்புகள்) 23 keyed leaks சரி செய்யப்பட்டன — «все matching», «только remote», «Открыть Scan», funnel «Evaluated → Applied…» உள்ளிட்டவை ஒவ்வொரு locale-இன் சொந்த ப்ரொடக்ட் சொல்லாக்கத்தை மறுபயன்படுத்தும் முழு மொழிபெயர்க்கப்பட்ட வாக்கியங்களாக மாறின. `i18n-no-latin-leaks` fragment அட்டவணை + funnel probe உடன் விரிவாக்கப்பட்டது (சிவப்பு→பச்சை).
- **நாணய தீர்ப்பு மாறுதல் (CAR-109)**: சம்பள ஒப்பீடு `comp-compare.mjs`-இல் server-பக்கத்திலேயே கணக்கிடப்பட்டு மரபுவழியாக உட்பொதிக்கப்படுகிறது (`Candidate minimum: … per YEAR (raw: …)` vs `JD offer: …`); மாதாந்திர ×12, k/к/тыс/萬 மற்றும் தசம-காமா வடிவங்கள் ஒப்பிடும் முன் இயல்பாக்கப்படுகின்றன; ஒரு ஐயப்பாடுள்ள மாற்றம் தன்னால்தான் தீர்ப்பை மாற்ற ஒருபோதும் முடியாது (zh-TW «€80–100k ниже минимума» வழக்கு இறந்தது). மாடல் என்றும் பெருக்காது.
- **Help ×18 பொத்தான் labels (CAR-107)**: மொழிபெயர்க்கப்பட்ட help bundles UI இனி காட்டாத ஆங்கில labels-ஐச் சுட்டியது («⚡ Run live», «Save», «Scan now») — view sources-இலிருந்து வரையப்பட்ட 263 மாற்றங்கள் 18 locales முழுவதும்; docs-assistant இந்தத் திருத்தத்தை மரபாகப் பெறுகிறது.

### சேர்க்கப்பட்டது

- **Precompressed bundle + cache செய்யக்கூடிய cold load (CAR-104)**: `make-bundle.mjs` வெளியீட்டு நேரத்தில் `bundle.js.br` (brotli q11) + `.gz` உருவாக்குகிறது; bundle-வரையறுக்கப்பட்ட middleware `Vary: Accept-Encoding`, `public, max-age=300, must-revalidate` + ETag/304 உடன் br > gz-ஐ negotiate செய்கிறது; freshness-வாயில் பாதுகாக்கப்பட்டது (ஒரு துணை உருவகம் ஒருபோதும் identity bundle-ஐ விடப் பழையதை வழங்காது), நேரடி artifact fetch-கள் 404 பெறுகின்றன, CSP byte-க்கு byte ஒரே மாதிரி. Cold load: 3.1 MB → ~0.6 MB wire (−80%); 5 நிமிடத்திற்குள் மறுவருகைகள் ≈0 bytes மட்டுமே பரிமாறுகின்றன.

## [1.258.0] — 2026-10-25

**ஏஜெண்ட் கூட்டத்தின் ஆறு திருத்தங்கள், ஒரே ரயில்: #/scan நிறுவன எண்ணிக்கை அண்டங்களைக் கலக்குவதை நிறுத்துகிறது, deep research மூலங்களைக் கோருகிறது, படிவப் பிழைகள் field-ஐ ஒளிரச் செய்கின்றன, loading நிலைகள் skeleton-களையும் உடனடி h1-ஐயும் பெறுகின்றன, மேலும் மதிப்பீடுகள் தங்கள் 37k-token prompt prefix-ஐ cache செய்கின்றன.**

### சரி செய்யப்பட்டது

- **#/scan «Active companies» எண்ணிக்கை (CAR-100)**: தொகுதி எல்லா முடிவு வரிசைகளிலும் உள்ள தனித்த நிறுவனங்களை எண்ணியது (ப்ரொடக்ஷனில் 1554 — hh.ru மட்டுமே நூற்றுக்கணக்கானவற்றைப் பங்களிக்கிறது), ஆனால் பகுதி API-சார்ந்த tracked நிறுவனங்களை மட்டும் எண்ணியது (~90) — ஒரு பின்னத்தில் இரு அண்டங்கள். இணைப்பு (a): தொகுதி இப்போது API-சார்ந்த tracked ஸ்கேன் அதுவே fetch செய்த வரிசைகளிடையேயே நிறுவனங்களை எண்ணுகிறது (`_entry ?? company` மூலம் பொருத்தப்படுகிறது; hh.ru/telegram முதலாளி வரிசைகள் விலகுகின்றன); pre-scan fallback அதே அண்டத்திற்குள் நகர்த்தப்பட்டது (அது «104/90» ஆகக் காட்டக்கூடும்).
- **Deep research புனைவு (CAR-110)**: deep prompt இப்போது ஒரு கடின ஒப்பந்தத்தைச் சுமக்கிறது — ஒவ்வொரு உண்மைக் கூற்றும் `[source: domain.com]` உடன் முடிய வேண்டும் (பெயரிட முடியவில்லை என்றால் → கூறாதே; அடையாளத்தைப் புனைவது «unknown» எழுதுவதை விட மோசமானது), தெரியாத உண்மைகள் `unknown` ஆக எழுதப்படுகின்றன, மேலும் அறிக்கை `## Data freshness` பிரிவுடன் கட்டாயம் முடிய வேண்டும். Freshness அங்கங்கள்: இன்றைய UTC தேதி + `POST /api/deep`-இல் விருப்பமான நிறுவன `url` (bounded, server-பக்கத்தில் ஒருபோதும் fetch செய்யப்படாது).
- **படிவப் பிழைகள் field-ஐ ஒளிரச் செய்கின்றன (CAR-130)**: தோல்வியுற்ற POST படிவத்தின் முதல் field-ஐ `aria-invalid` + `.is-error` உடன் குறித்து அதில் focus வைக்கிறது (WCAG 3.3.1); edit செய்யும்போது நீக்கப்படுகிறது. Network-பிழை hint இப்போது deployment-ஐ அறிகிறது — loopback dev-கட்டளை hint-ஐ வைத்திருக்கிறது, டிப்லாய் செய்யப்பட்ட origin `bash web-ui/bin/start.md` ஆலோசனைக்குப் பதிலாக «server is not responding» பெறுகிறது (connection பேனரிலும் இதே hardcode இருந்தது).
- **Loading நிலைகள் (CAR-112)**: #/map மற்றும் #/tracker தங்கள் h1-ஐ உடனடியாக ரெண்டர் செய்கின்றன (தரவு வரும் வரை router focus இலக்கே இருந்ததில்லை), மேலும் ஒரு பகிர்ந்த skeleton helper (`Skeleton.rows`, `role="status"` பிராந்தியத்திற்குள் இருக்கும் aria-hidden shimmer வரிசைகள் — `common.loading`-ஐ மறுபயன்படுத்துகிறது) tracker, scan முடிவுகள் மற்றும் map shell-இல் வெறும் «Loading…» உரையை மாற்றுகிறது; `prefers-reduced-motion` துடிப்பை நிறுத்துகிறது.

Confidencial முதலாளிகள் சரியான லேபிள் பொருத்தத்தில் விழுகிறார்கள் («Confidencial Seguros» உயிர்ப்புடன்), `max_pages` 100-ஆகக் கட்டுப்படுத்தப்பட்டது — offset 10,000-க்குப் பிறகு API 400 தரும், truncation எச்சரிக்கை இப்போது வரம்பை உயர்த்தாமல் முக்கியச்சொற்களைச் சுருக்கச் சொல்கிறது.

- **Liveness: தனிவரிசை பேனர் மேலிருக்கும் வரியின் பகுதி அல்ல** — வேலைக்குக் கீழே «Sign in if you want to apply» / «Get notified when this position is filled» என்பது அது இருக்கும் முடிவுறுத்தல் பிரிவாகவே படிக்கப்படுகிறது; வரிகளின் குறுக்கே இருக்கும் உண்மையான «until filled» இன்னும் active ஆகவே படிக்கப்படுகிறது.
