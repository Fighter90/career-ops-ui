## [1.248.1] — 2026-10-09

**`location_filter` பேரண்டின் `always_allow` மற்றும் `block_hard` நிலைகளைப் பெறுகிறது (CAR-60) — பல-நாடு இட வரிசை தடைசெய்யப்பட்ட சகோதர-பட்டியலைத் தாண்டுகிறது, வெளிப்படையான கடின தடையை இனி மீட்க முடியாது.**

### சரி செய்யப்பட்டது

- `always_allow` `block`-ஐ வெல்கிறது: `block: [romania, poland, croatia]` மற்றும் `always_allow: [united kingdom]` இருக்கும்போது, workable-இன் இணைக்கப்பட்ட செல் «London, United Kingdom · Romania · Poland · Croatia» கடந்து செல்கிறது — சொந்த பிராந்தியம் ஒரு விருப்பம் (workable #4806-இன் நுகர்வோர் வழக்கு, இப்போது பேரண்ட் வடிவில்).
- `block_hard` `always_allow`-ஐ வெல்கிறது: வரியின் வேறு இடத்தில் always_allow பொருத்தத்தால் ஒருபோதும் மீட்கப்படக்கூடாத நாடு-நிலை சொற்கள்.
- `strict: true` இப்போது `block_hard`-ஐ கட்டுப்படுத்தும் நிலையாகக் கணக்கிடுகிறது; docs/help-இன் location_filter பகுதி இரு நிலைகளையும் ×18 ஆவணப்படுத்துகிறது.

### குறிப்புகள்

- இம்முறை வேண்டுமென்றே போர்ட் செய்யவில்லை: பேரண்டின் word-boundary இட முக்கியச்சொல் தொகுப்பான் மற்றும் USPS மாநில அட்டவணை (web-ui substring பொருத்தத்தையே வைத்திருக்கிறது; அட்டவணை அமெரிக்க-மைய கட்டமைப்புகளுக்கே — தேவைப்பட்டால் CAR-60-இன் கீழ் இணைக்கவும்). workable நுகர்வோர் சோதனையின் இடைக்கால allow-list வடிவம் புதிய பேரண்ட் வடிவத்துடன் இரண்டாவது தீர்ப்பாக நீடிக்கிறது.

## [1.248.0] — 2026-10-09

**பேரண்ட்-பாரிட்டி: மேல்நிலை ஐந்து provider/liveness திருத்தங்கள் போர்ட் செய்யப்பட்டன — API-ஐ நகர்த்திய போர்டுகள் தொடர்ந்து வேலை செய்கின்றன, தனிவரிசை முடிவுறுத்தல் பேனர் இனி தவறவில்லை.**

### சரி செய்யப்பட்டது

- **Gupy API-ஐ `portal.gupy.io`-ஐப் பின்தொடர்கிறது**, மேலும் API உண்மையில் படிக்கும் வடிகட்டி பெயர்களை அனுப்புகிறது (`workplaceType`/`type`) — பழைய பன்மைப் பெயர்கள் மௌனமாகப் புறக்கணிக்கப்பட்டன; `country` இனி அனுப்பப்படாது (கட்டமைக்கப்பட்ட நாடு அனுப்புவதற்குப் பதிலாக உள்ளீட்டுப் பெயருடன் எச்சரிக்கை வரைகிறது). Confidencial முதலாளிகள் சரியான லேபிள் பொருத்தத்தில் விழுகிறார்கள் («Confidencial Seguros» உயிர்ப்புடன்), `max_pages` 100-ஆகக் கட்டுப்படுத்தப்பட்டது — offset 10,000-க்குப் பிறகு API 400 தரும், truncation எச்சரிக்கை இப்போது வரம்பை உயர்த்தாமல் முக்கியச்சொற்களைச் சுருக்கச் சொல்கிறது.
- **Workable பல-நாடு வேலையின் எல்லா நாடுகளையும் வைத்திருக்கிறது**: ஒரே job-URL-இன் கீழ் சகோதர-பதிவுகள் ஒரே வரியாக மடிகின்றன („London, United Kingdom · Romania · Poland · Croatia“) — முதல் நாடு வெல்வதில்லை.
- **Liveness: தனிவரிசை பேனர் மேலிருக்கும் வரியின் பகுதி அல்ல** — வேலைக்குக் கீழே «Sign in if you want to apply» / «Get notified when this position is filled» என்பது அது இருக்கும் முடிவுறுத்தல் பிரிவாகவே படிக்கப்படுகிறது; வரிகளின் குறுக்கே இருக்கும் உண்மையான «until filled» இன்னும் active ஆகவே படிக்கப்படுகிறது.
- **Radancy லெகசி கார்டு மார்க்அப்பில் சகோதர `job-location` உறுப்பைப் படிக்கிறது** (Barclays-குடும்ப அமைப்புகள் இடத்தை `</a>`-க்குப் பிறகு வைக்கின்றன) — சொந்த இடமில்லாத வரிசைகள் காலியாகவே இருக்கின்றன, அண்டையின் இடத்தைக் கடன் வாங்குவதில்லை.
- **SmartRecruiters ஃபால்பேக் வேலை இணைப்புகள் கட்டமைக்கப்பட்ட slug-ஐ வைத்திருக்கின்றன** — நம்பத்தகுந்த அல்லாத/இல்லாத `ref` கொண்ட வேலை அதன் பொது URL-ஐ tenant slug-இலிருந்து உருவாக்குகிறது, காட்சி-பெயரிலிருந்து ஒருபோதும் இல்லை.

### சேர்க்கப்பட்டது

- No-ports ஆவணப்படுத்தப்பட்டது: மேல்நிலை `_http` proxy `fetchImpl` திருத்தம் (web-ui-இல் proxy கிளையே இல்லை — போர்ட் செய்தால் DNS-rebinding காவலரின் identity-சோதனை செயலிழக்கும், repo வேண்டுமென்றே தவிர்க்கும் undici சார்பு சேரும்); மேல்நிலை `verify-ats` (+226 வரிகள்) மற்றும் `cv-facts` (web-ui தன் சொந்த ATS ஸ்கோரிங், CV பார்சிங் செயல்படுத்துகிறது); பேரண்ட் டாஷ்போர்டு Go TUI மற்றும் CLI ஸ்கிரிப்ட்கள்; Teamtailor import மறுவரிசை (அழகுப்பணி).

### குறிப்புகள்

- அறியப்பட்ட இடைவெளி follow-up ஆக: பேரண்ட் location வடிகட்டியின் `always_allow` நிலை (workable நுகர்வோர் சோதனை இதன் மூலம் UK தடையைத் தாண்டுகிறது) web-ui-இல் இல்லை; போர்ட் அதே நுகர்வோர் முடிவை allow-list சோதனையால் வெளிப்படுத்தியது. தனிமாற்றமாகப் பதிவு செய்யப்பட்டது.

- இருள் டைல்களின் இயல்புநிலை OSM-இன் CSS மாற்றமே — கீ இல்லாத Carto தன் basemaps-ஐ API கீக்குப் பின்னால் மூடியது (கோரிக்கையால் சரிபார்க்கப்பட்டது); keyed preset ஒரு opt-in, இயல்புநிலை அல்ல.

- **CV மார்க்டவுன் LTR-இலேயே.** அரபியில் textarea மற்றும் முன்தோற்றம் `dir="ltr"`-உடன் வரையப்படுகின்றன; சுற்றியுள்ள சட்டகம் RTL-இலேயே.
