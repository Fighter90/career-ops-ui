- **Status:** Done (backfilled 2026-10-27 — the wave shipped spec-less; this file closes the CAR-113/123 assessment item R6)

## Goal

A user opening any core view sees one designed product — a single primary action, real
data before LLM calls, safe bulk operations with undo, and consistent empty/loading
states — instead of twelve independently-grown pages.

## Context

**Honest framing: this is a BACKFILL.** The wave was assessed and queued as Linear
CAR-113…125, executed through the fixer → review → go pipeline, and merged commit by
commit — but no spec was written before or during the work, violating
`docs/sdd/HANDOFF.md` post-release rule 4 ("a spec per phase/release"). This file was
written after the fact (2026-10-27) from the merged evidence; every claim below cites
its commit/PR.

Forcing facts at wave start (from the assessment and PROGRESS `5083b967`):

- The dashboard offered twin red hero CTAs and no status overview; the tracker table
  broke its grid («2026-/08-25» two-line dates) and had no bulk path; reports/scan/
  pipeline filtered through whole-DOM re-renders that lost focus and state.
- Every AI view hand-rolled its own streaming layout (12 divergent copies).
- First-run screens opened on bare form-and-button panels.
- v1.260.0's remote-QA pass found the deep-view overflow at 390 px (CAR-146) — the
  mobile contracts were already strained before the wave.

## Acceptance criteria (as shipped)

1. Every redesigned cluster carries its own red→green suite (named per cluster above);
   per-suite counts come from the commit bodies, never asserted globally.
2. No new dependency, no build step, CSP-safe DOM everywhere (`UI.el` /
   `createElementNS` for SVG); CAR-125 ships without a single dict edit.
3. No invented write endpoints: tracker moves via the existing `POST /api/outcome`,
   portals via the existing `POST /api/portals/toggle`; the one new endpoint
   (`POST /api/pipeline/restore`, CAR-151) is lock-guarded and `isValidJobUrl`-gated.
4. i18n: every new key reached ×19 parity before merge (temporary allowlists —
   `CAR115_PENDING`, the `llm2.*` exemption — were dropped after fan-out; the dict
   keeps zero dead keys).
5. Reduced motion is honoured wherever motion was added (count-up, parallax, cluster
   animation, chart entrance); drag & drop is never the only path (keyboard Move);
   destructive targets are `UI.confirm`-gated.
6. Whole-tree gate on this spec's base (real run, 2026-10-27):
   `node --test tests/*.test.mjs tests/acceptance/*.test.mjs` → **6428 pass / 0 fail /
   6 skipped** (188 s).

## Plan — what actually happened

The wave ran as per-cluster agents through the «фиксер → ревью → go» pipeline
(PROGRESS `5083b967`): one fixer agent per cluster → an independent review pass →
maintainer go → squash-merge. Review findings folded into the squash (CAR-114's
LOC/z-index round; CAR-119's rounds 1/#3/#11) or shipped as follow-up PRs (CAR-125
#509, CAR-151 #508). CAR-115's first agent lost its worktree uncommitted — the salvage
snapshot is kept in the PR history deliberately. CAR-116/118 rode the v1.260.0
review-hardening train and shipped before the rest of the wave. No spec existed during
any of this — that omission is what this backfill closes.

## Risks and invariants touched

- **R-07 (CSP-safe DOM):** the whole wave adds client DOM — every cluster uses
  `UI.el`/`createElementNS`; the Playwright suites (nav-v2, tracker-v2, pipeline-v2,
  car124-empty-states, playwright-map) assert no CSP violations.
- **R-08 (i18n parity):** new `pipe.*`/`rep2.*`/`llm2.*`/`scan.v2.*` keys — covered by
  `tests/i18n-coverage.test.mjs` after the ×19 fan-outs landed.
- **R-11 (pipeline dual format):** CAR-151's restore must not corrupt either format —
  `restorePipelineLines` reinserts byte-faithfully with format-switch normalization,
  gated by `tests/pipeline-restore.test.mjs`.
- **R-05 (counts):** CAR-119's kit moved the bundle script count 93 → 94; the bundle
  count gate pins it.
- **Pipeline skip contract:** CAR-116's undo interplays with `markPipelineRejected`'s
  Rejected-section marks — the undo path restores via the same writers, not raw edits.
