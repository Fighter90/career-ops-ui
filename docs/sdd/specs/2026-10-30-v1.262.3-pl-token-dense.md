# SPEC — v1.262.3: pl joins the token-dense evaluation locales

> Status: SHIPPED (the release spec; Verification filled with real output before the release merged).
> A single-purpose patch: the same deterministic wall that moved `it` in v1.262.1, now caught
> for Polish by the full remote-QA plus an identical spot re-run.

## Goal

The full remote-QA on prod v1.262.1 caught the Polish evaluate dying at the standard ceiling —
`502 · openrouter · 300 s · 0 ch` — and the spot re-run dispatched with v1.262.2 reproduced it
exactly (runs **40960568766** full ×19 and **40968958062** spot): 18/19 locales passed A–G,
`it` finished at 302 s inside the token-dense 480 s clock, and `pl` hit the wall twice with
zero output. A deterministic timeout, not a flake — the same shape class that earned `ta`
(v1.261.1, CAR-174), `hi` and `it` (v1.262.1) their budgets. Give `pl` the token-dense budget.

## Scope

1. **`pl` → `TOKEN_DENSE_EVAL_LOCALES`** (`ta`, `hi`, `it` → `ta`, `hi`, `it`, `pl`,
   `server/lib/routes/llm.mjs`): both the 32 768-token budget and the 480 s clock apply;
   `/api/evaluate` and auto-pipeline stay on the one source of truth (`evalMaxTokens`); the 18
   standard locales keep the 300 s clock.
2. **Red-first pin, now incl. the clock:** `evalMaxTokens('pl') === 32768` **and**
   `evalTimeoutMs('pl') === 480_000` in `tests/evaluate-truncation.test.mjs` — both cases fail
   against the old maps, `pl`/`pl-PL` at 32768 + 480 s asserted after (#607). The v1.262.1 `it`
   patch pinned only the token map; the clock pin closes that gap for the locale that actually
   died on time, not tokens.

**Out of scope (deliberate non-actions):**

- Nothing else bundled — the v1.262.2 review-tail content went out as its own release; this
  patch carries the pl fix only.
- No change to the 18 standard locales (300 s) or to `ta`/`hi`/`it` — no drift observed for
  them in either run.

## Acceptance criteria

1. `/api/evaluate` with `lang=pl` requests `max_tokens=32768` under a 480 s ceiling;
   auto-pipeline inherits the same `evalMaxTokens`; both pinned red-first, the clock pin
   included.
2. The 18 standard locales keep 300 s; `ta`/`hi`/`it` budgets unchanged.
3. Ship train: test:ci green (6867 → 6868), CHANGELOG ×19 parity, QA prompt updated, prod
   deploy verified, and a post-deploy pl evaluation re-run closes the loop.
