# SPEC — v1.262.2: the review-tail patch

> Status: SHIPPED (the release spec; Verification filled with real output before the release merged).
> One patch closing the tails of the v1.262.x wave review: 7 low-severity findings red-first,
> the deploy-workflow hardening (F1–F6), the import-modal SPA tail, and the docs-drift sweep.

## Goal

The wave review of v1.262.x left a tail of low-severity findings that were real but below the
release bar: data-correctness holes in the fresh v1.262.0 features (CSV import, cv-voice,
`years_min`, posting-guard capture listing, deel, MiniMax), an arbitrary-command-execution hole
in the new `mode=provider` deploy input, raw secrets in the public hermes diagnostics log, and
the small SPA rough edges of the import modal. Close every one red-first, and sweep the docs
drift the fast wave cadence had accumulated.

## Scope

1. **7 wave-review L-findings, each red-first:**
   - **CSV import backslash round-trip** — a `\` in a cell was written doubled and read back
     doubled, so re-importing the same CSV missed the company+role dedup and could create a
     duplicate row; the reader now unescapes `\\` after the split (write→read round-trip is
     lossless, a re-import dedups).
   - **cv-voice `<head>` strip quadratic** on unclosed tags — 4827 ms → 13 ms on the 64 KB
     input the route caps at.
   - **`statedYearsMin` lazy** — the full years-parser ran for every job of every source even
     when `years_min` was not configured; now lazy, the seconds of CPU per large scan are gone.
   - **Capture TOCTOU** — a capture deleted between `readdir` and `statSync` crashed the
     posting-guard listing; vanished files are skipped.
   - **MiniMax CN wildcard** — the CN default matched only `api.minimax.cn` exactly; any
     `*.minimax.cn` base URL now gets the CN model.
   - **Deel `$`-tokens** that are not hex refs no longer leak into the snippet as literals
     (broken short `$`-reference descriptions are skipped).
   - **Client `file.size` guard** — the import picker checks `file.size` BEFORE `file.text()`:
     the 512 KB server cap answered 413 only after the browser had parsed a possibly huge
     file; localized `import.tooLarge` toast ×19.
2. **Deploy workflow hardening (F1–F6):**
   - **F1 provider-input injection** — `provider` was the only input interpolated into the
     remote shell without charset validation; a `'` in the value broke out of the quoting and
     ran arbitrary code on prod. Whitelisted `^[A-Za-z0-9_-]+$` before any splice, and the
     key-guard grep can no longer false-pass.
   - **F2/F3 hermes log redaction** — the hermes diagnostics step printed raw journalctl +
     unit dumps to the public log, and its filter missed uppercase `*_API_KEY=` while masking
     nothing. Now a shared case-insensitive redact + value masking + 80-char truncation on all
     three sinks, `?token=` query strings masked too.
   - **F4 `app_dir`** — the hermes step ignored `inputs.app_dir` and hardcoded
     `/opt/career-ops/src/.env`.
   - **F5 `public_url` https** — it reached curl without an https check (option injection via
     a leading `-`).
   - **F6 anti-downgrade executable gate** — the v1.238.0 incident fix had no executable gate:
     six new pins in `ci-workflows` (refs have no defaults, the guard runs before Deploy,
     strict refs regex); gate count 11 → 17.
3. **Import-modal SPA tail:** the modal arms the same nav guard as the outcome modal
   (navigating away no longer leaves it orphaned on top of another view); the hidden file
   input is removed on `cancel`, not only on `change` (repeated dismissals no longer leak
   inputs into `document.body`); `plan.duplicates` is read through the guarded form in the
   preview; tracker `num` allocation uses `reduce` instead of `Math.max(...spread)` — the
   spread hits the argument limit at ~100k rows.
4. **Docs:** the help guide's «118 EN adapters» bullet now carries the count in fr/it/ta (the
   other 15 locales already had it); vendor prices on cvstart.org re-verified against the
   official pricing pages — all four unchanged, `CHECKED_ON` → 2026-10-30; a post-release
   drift sweep fixed 42 stale count/version lines across 23 files (README ×19, `CONTEXT.md`,
   `CLAUDE.md`, the SDD manuals, `PROJECT-CONTEXT`).

**Out of scope (deliberate non-actions):**

- The cv-studio native `window.confirm` (CAR-179 era) stays — converting it to `UI.confirm`
  is a follow-up, not a patch item.
- The `<mark title>` stock-phrase tooltip stays tooltip-only (acceptable a11y floor).
- `remote-qa.yml` keeps `cancel-in-progress: true` — re-dispatching intentionally supersedes
  a running regression.

## Acceptance criteria

1. Every L-finding carries a failing-test-first pin; the CSV write→read round-trip is
   lossless and a re-import of the same CSV dedups to one row.
2. `mode=provider` validates the value against `^[A-Za-z0-9_-]+$` before any shell splice;
   the hermes diagnostics print no raw secret (case-insensitive redact + masking + truncation,
   `?token=` masked); `app_dir` is honoured; `public_url` is https-gated before curl; the
   anti-downgrade guard is pinned executable — the ci-workflows gate count rises 11 → 17.
3. The import modal closes on navigation, the file input is cleaned on cancel, the duplicate
   preview is guarded, and `num` allocation has no spread-argument limit.
4. Docs parity: help fr/it/ta carry «118»; cvstart prices carry `CHECKED_ON 2026-10-30`; the
   drift sweep leaves no stale count/version line in the 23 swept files.
5. Full ship train: test:ci green, CHANGELOG ×19 parity, QA prompt v1.262.2 (v1.262.1
   archived to `qa/archive/superseded-prompts/`), README ×19 banners, prod deploy verified.
