## Goal

v1.263.0 shipped with known tails: the tracker had no way to change a row's status
from the web (BACKLOG v1.246.0 #2, the parent-parity port), the server's evaluation
`warnings` array (output-token truncation, language drift, date corrections) was
computed and then silently dropped by six client surfaces, and the coverage ratchet
owed four route files + the habr source a dedicated pass. A six-agent post-release
hardening wave closed all of that on `main`, fixed two real scan-source defects the
coverage work surfaced (trudvsem's dead envelope, habr's tag resurrection), tightened
two ingress gates (raw profile `full_name`, truthful upload/model hints), repaired the
help renderer-leak class across all 19 bundles, and published the Linear CAR-191…216
closure bundle for the owner. The release chore (version, EN changelog, QA prompt,
baselines, banner, help §11 paragraph) sits on `release/1.264.0-integration`; the ×18
locale fan-out (README + CHANGELOG) is in flight at spec time.

## Scope

1. **Inline tracker status edit** (`feat/tracker-inline-status` + route-review):
   `POST /api/tracker/status` relays the parent's canonical `set-status.mjs` under the
   `applications.md` lock — state whitelist via `states.mjs`, `--dry-run`/`--note`
   passthrough, fail-soft 502 with sanitized detail, argv-array spawn. Client: every
   `#/tracker` row's status badge is a compact `<select>` fed by `GET /api/tracker/stages`
   (never a hardcoded whitelist, i18n ×19); success updates the row in place (tone class
   + tab counts, focus kept), failure reverts and toasts. Route-review LOW fixes: rows
   the relay cannot address — a hand-edited unknown status, a backfill sentinel `#` —
   keep the read-only badge instead of a blank or never-addressable select.
   **Reviewer verdict: no HIGH/MED findings.** Red-first suites:
   `tests/tracker-inline-status.test.mjs` (+ the missing/empty-state 400 branch pin);
   `docs/architecture/API.md` hand-off; BACKLOG v1.246.0 #2 closed in the same train.
2. **Server warnings surfaced on every AI page** (`fix/warnings-surface`): `evaluate`,
   `deep`, `auto-pipeline` (page **and** modal — the modal pipeline dropped the
   done-frame warnings), `career-plan`, `market`, `cv-studio` (humanize + tailor) now
   render the server `warnings` array as a `badge-warn` band (`role="status"`).
   New key `llm.truncatedNotice` ×19. Red pin: `tests/llm-warnings-ui.test.mjs`.
3. **Coverage wave (+111 tests)**: `routes/map.mjs` 100/94.9, `geocode.mjs` 96.3/92.9,
   `content.mjs` 99/84.9, `networking.mjs` 96.4/89.1, and a dedicated
   `tests/sources-habr.test.mjs` at 100/98.2 (new `tests/cov-*-routes.test.mjs` ×3);
   the branch floor held at ≥ 90 %.
4. **Trudvsem envelope fix** (`fix/trudvsem-envelope`, live end-to-end verified): an
   empty page (`results: {}`, also "past the end") returns clean zero rows instead of
   killing the whole scan; HTTP-200 bodies carrying the API's `status: 500` envelope
   throw with the API's own text; pagination walks **record** offsets (was page-index —
   pages silently duplicated, ~52 vacancies instead of hundreds); the walk stops before
   the deep-offset failure zone (`offset × limit ≥ 10000`).
5. **habr strip-after-decode** (hh.mjs parity): titles/companies are tag-stripped
   **after** entity decoding — `&lt;script&gt;` in a card title can no longer reach
   scan rows as live markup, while legitimate `>>` in titles survives.
6. **Raw profile `full_name` gate**: `PUT /api/profile` (raw path) refuses a
   `candidate:` block without a non-empty `full_name`, the same line the fields-merge
   path already held (it used to persist `full_name: null`).
7. **Hints truthfulness**: `.doc` removed from the CV upload accept list and
   `cv.uploadHint` ×19 (the parser never supported it); `config.openaiModelHint` ×19
   names `gpt-5` (the server maps any `*-codex` id to it); `config.anthropicModelHint`
   ×19 and the **Anthropic default** mirror the parent's tiers — default
   `claude-sonnet-5-5`, premium `claude-opus-5-5`. **The default model changed**: deploys
   that relied on the old silent default (`claude-sonnet-4-6`) upgrade automatically;
   pin `ANTHROPIC_MODEL` in `.env` to opt out.
8. **Claude Code docs link** → `code.claude.com` (the old `docs.anthropic.com/…claude-code`
   URL TypeErrors in the links gate).
9. **help ×19 renderer-leak class** (the post-release prose pass, landed on `main`
   after v1.263.0 — this is the first tag carrying it): the Row-density bullet is gone
   (the toggle left the UI in v1.263.0), 18 broken `**bold**` span families repaired,
   and the leak class itself fixed ×19 — a second blank line after every
   table-before-paragraph (the table regex ate the row's trailing newline) and the pipe
   glyph dropped from bold cells: **0 literal `**` in render across all 19 help
   bundles**. The release chore adds the §11 inline-status paragraph (EN source).
10. **Linear CAR-191…216 closure bundle**

## Acceptance criteria

1. Tracker: the row select offers only the canonical stages; a change POSTs and updates
   the row in place; a failure reverts and toasts; unknown-status and sentinel-`#` rows
   render the read-only badge; the route's dry-run mode echoes.
2. The warnings band appears on all six live-generation surfaces **including** the
   auto-pipeline modal's done frame.
3. The five coverage targets sit at their measured numbers and the ≥ 90 % branch floor
   holds (`npm run test:coverage:gate`).
4. A trudvsem scan survives an empty page and stops short of the deep-offset zone;
   walking the offsets does not grow the dedup set; habr titles never resurrect markup.
5. Raw `PUT /api/profile` 400s a `candidate:` block without `full_name`; hints ×19 are
   truthful (`.doc`-free, `gpt-5`, Anthropic 5-5 tiers).
6. help ×19 keep 33 H2 / 129 H3 and 0 literal `**` in render.
7. Ship train: `npm run test:ci` green (6905 → 7041), CHANGELOG ×19 parity, the
   v1.264.0 QA regression prompt, prod deploy + verify, remote-QA — **pending at spec
   time** (deploy follows the release).
