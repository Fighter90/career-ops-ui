# SPEC — v1.263.0: the owner UX batch

> Status: SHIPPED (the release spec; Verification filled with real output before the release merged).
> A design-correctness minor, not a feature train: the owner sent 10 screenshots of UX
> defects and asked for a full design audit; nine read-only agents turned them into
> 26 Linear tasks (CAR-191…216), and three red-first fix branches (plus the accent
> branch) landed them as one release.

## Goal

Ten owner screenshots — each a defect a user hits within a minute of use: the `#/scan`
sticky header painting over the topbar search once scrolled; the salary popover
rendering its inputs 200 px tall; the density toggle whose label logic the owner chose
to remove outright; the dashboard hero glued into one line box; a help TOC that reflowed
all 33 rows on every scroll-spy step; a mobile drawer with a phantom fade and no visible
✕; a docs-assistant answer with a long URL stretching the page horizontally; «Недавние»
with no explanation and no way to clear; a career-plan Save dead after a failed load; an
evaluate URL-prefill that burned an LLM call on its own paste-placeholder; an
auto-pipeline that started a paid run on an IME composition Enter — plus
placeholder-only controls screen readers do not reliably voice.

The owner also asked for a full design audit. Nine read-only agents ran it: five
root-cause passes over the screenshots, a contrast-math pass (296 foreground/background
pairs), a dead-handler sweep over 197 + 19 buttons, a forms pass, a motion inventory,
and a visual sweep over 48 screenshots. The findings became 26 Linear tasks
(CAR-191…216). The owner-batch fixes landed directly on `main`; three fix branches
merged red-first on top (`fix/motion-css`, `fix/a11y-w2`, `fix/sweep-fixes`) plus the
owner-requested accent branch (`fix/accent-red`).

## Scope

1. **motion.css — the cascade-last motion layer** (fix/motion-css; CAR-196, CAR-207):
   modal/popover entrances (scale .97 + fade, 130–240 ms), toast spring-in + an animated
   leaving state (`data-leaving` + animationend + a 200 ms fuse in api.js),
   theme-toggle press spring, chip/tab press scale(.97), stagger infrastructure
   (50 ms steps, cap 12), and a `.page-enter` route-change rise in router.js (never on
   first paint, never on a same-route re-render — a language switch must not replay it).
   All 68 unguarded hover-lift rules are `(hover: hover)`-gated (touch devices kept
   stuck lifts), and the card lift is interactive-only (`.card:has(a)` / `a.card` /
   `button.card` / `[role=button].card`). Every rule carries a
   `prefers-reduced-motion` neutralizer (modal keeps an explicit `opacity: 1`); the
   car112 skeleton contract stays in overlays.css verbatim. Pinned by
   `tests/ux-motion.test.mjs` (15 pins, red against a pristine main snapshot).
2. **Accent blue → crimson, hue 15** (fix/accent-red; owner request, logo-coherent,
   WCAG-verified): the 5 cv3 accent tokens flipped in all three theme blocks of
   tokens-v3.css (light, dark, prefers fallback); docs-assistant chat-bubble text rides
   `--accent-ink` (the literal `#fff` was 2.39:1 in dark), the funded chip wash rides
   `--accent-soft`; danger stays hue 25 with its own treatments. Six design/contrast
   gates 40/40 green.
3. **Contrast pass** (WCAG audit over 296 pairs → 8 text FAILs + a 1.4.11 boundary
   class): docs-fab gradient 2.43 → 6.4:1; toast.success on the ok-soft pair; the banner
   btn-dark flipped to `--ink`; form-control borders to 3:1 (`--cv3-input-line`, was
   1.2:1); light variants for scan-logbtn / reposts-badge / fab-chip / close.
4. **#/scan**: the sticky thead z-index drops 5 → 1 (both header layers carried the
   topbar's z and the thead was later in the DOM — red-first Playwright probe asserts
   via `elementFromPoint`); the salary-popover fix scopes `.v2-scan-bar .input` to `>`
   plus a mirror guard (the 200 px flex-basis was being read as HEIGHT inside the
   popover's column flex); the Compact density toggle is removed by owner decision
   (the scan-results plumbing stays under car115, i18n keys removed ×19).
5. **The owner-batch wave on main**: dashboard hero → column flex; help TOC rows
   reserve their gutter inline (transparent `border-inline-start`) and the section
   number moves to its own end-aligned column — the list no longer reflows per
   scroll-spy step; the mobile drawer gains a visible ✕, a scrollTop reset on open, and
   gates the phantom `--paper` fade to `.has-hud`; docs-assistant gets the grid
   `min-width` chain + `overflow-wrap: anywhere`; «Недавние» gains a hint (title +
   aria-label, synced by the language switcher) and an immutable Clear chip; career-plan
   re-arms Save after a failed load (the two-pager contract) and its Input tab gains the
   ×19 `plan.resultNote` that doubles as a redirect; the evaluate URL-prefill template
   is detected before `run()` (toast `eval.pasteJd` ×19); auto-pipeline copies the
   CAR-21 IME gate.
6. **a11y — every control named (CAR-209)**: `A11yDump.label` names all 16 readonly
   LLM-output dumps (one shared key `a11y.readonlyOutput` ×19); 12 placeholder-only
   fields got programmatic names — the six owner-flagged (scan filter text, tracker
   score select, outcome-modal note, career-plan editor, auto URL input, bug-report
   textarea) plus the config raw editors ×2 and placeholder-key reuse for the rest;
   `tests/a11y-form-wires` now enforces the contract class-wide — 26 unnamed sites →
   0 + a documented allowlist.
7. **Visual sweep ×7** (fix/sweep-fixes): CAR-210 the tracker empty state renders
   full-width outside the 760 px-min table at 390 px (a filter that excludes everything
   keeps the short in-table notice); CAR-211 the collapsed scan console clips one line
   with an ellipsis instead of half-clipping a wrapped second line; CAR-212 the stats
   «?» hint gets a logical divider + a 44 px touch target; CAR-213 the career-plan
   Input tab explains where the generated plan lands; CAR-214 the 18 broken bold spans
   of help §1 (+ the rest the repo-wide unpaired-`**` scan surfaced) complete on their
   own lines — `UI.md()` renders a span broken across blockquote lines as literal
   asterisks; CAR-215 the docs FAB shrinks to 44 px at 12 px insets on phones (it
   covered real content at 390 px); CAR-216 the dashboard funnel empty state follows
   the v2-empty pattern (title + explanation + the real first-step action, keys ×19).

**Out of scope (deliberate non-actions):**

- **Skeleton sweep stays out** — the car112 contract pins the current fade verbatim in
  overlays.css; a rework is a separate design decision, not a batch item.
- **Theme-toggle icon crossfade** stays a `display` swap — the theme-toggle Playwright
  contract observes exactly that.
- **`.btn:active` scale not duplicated** — app.css owns scale(.98); motion.css
  deliberately leaves `.btn` alone.
- **Stagger is infrastructure only** — no surface adopts it in this release; the
  dashboard tiles take it in a later pass.
- **Help ×19 prose** (the density mention at en.md:1079, §1 markdown beyond the EN
  source, «118») rides the next fan-out; only the EN source moved here.
- **CAR-141 demo video** — owner action, not agent work.

## Acceptance criteria

1. Motion is reduced-motion-safe by construction (every rule neutralized), touch
   devices keep no stuck lifts, and route-enter fires only on a genuine route change.
2. Every input/textarea carries a programmatic name and every readonly dump is named
   (the class-wide gate enforces it); the contrast audit's 8 text FAILs + the 1.4.11
   boundary class are closed; the accent is crimson in light and dark with danger still
   distinguishable.
3. The scan header sits under the topbar when scrolled, the popover inputs are
   normal-sized, the density button is gone, and the seven visual-sweep defects render
   correctly at 390 px.
4. Ship train: test:ci green (6869 → 6905), CHANGELOG ×19 parity, the v1.263.0 QA
   regression prompt, prod deploy verified, README/help screenshots regenerated.
