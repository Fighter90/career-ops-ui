# Spec — CV Studio (Epic 21, v1.92.0)

## Problem

The `#/cv` page lets the user write/import a CV but offers no feedback on its quality, no safe way to share it, and no help making AI-generated bullets sound human. Epic 21 (CV Studio) is a large basket — template gallery, live preview, Word export, make-it-human, voice matching, résumé diagnostics, privacy masking, edit-and-regenerate, posting-PDF archive. This release delivers the **analysis + privacy + voice** core; the export/template/archive items are tracked as follow-up.

## Approach

A new `#/cv-studio` SPA view that reads `cv.md` via the existing `GET /api/cv` and offers three tools:

1. **Résumé diagnostics** — `public/js/lib/cv-diagnostics.js` exposes `window.CvDiagnostics.analyze(md)` returning a 0–100 score + per-check findings (length, quantified impact, weak verbs, buzzwords, sections, contact). Pure, deterministic, client-side. Near-empty CVs short-circuit to 0 so absence-passes don't inflate the score.
2. **Privacy mask** — `public/js/lib/cv-privacy.js` exposes `window.CvPrivacy.mask(md, opts)` returning redacted markdown + counts. Regex redaction of email/phone/links/handles/address + optional name→initials. In-browser only; the ≥7-digit phone guard avoids masking years/versions.
3. **Make it human / voice match** — `server/lib/routes/cv-studio.mjs` `POST /api/cv-studio/humanize` inlines `voice-dna.md` + up to 3 `writing-samples/*.md` (new `PATHS.voiceDna` / `PATHS.writingSamplesDir`) and builds a rewrite prompt with a hard no-fabrication guardrail. Live via the shared `runActiveProvider` cascade, or a copy-paste prompt.

## Data contract

Read: `cv.md` (client), `voice-dna.md` + `writing-samples/` (server, style-only per DATA_CONTRACT). **No writes** — the user edits their CV via the existing `PUT /api/cv`. The humanize rewrite may re-voice but never introduces new facts.

## Security

`llmRateLimit` on `/humanize`; text cap (20 KB); CSP-safe view (`UI.md()` XSS boundary, readonly textarea for prompt); the two libs are browser-classic scripts loaded before the view. No filesystem writes at all.

## Tests

`tests/cv-diagnostics.test.mjs` (analyze scoring on strong/weak/empty CVs + mask redaction/counts/toggles/name-initials/year-safety) and `tests/cv-studio-routes.test.mjs` (voice-context inlining, guardrail presence, manual fallback with no fabrication, min-length rejection). Libs loaded via the `new Function('window', staticFile)` pattern (no untrusted interpolation), same as fit-score/countries tests.

## Out of scope (follow-up CV Studio work)

Template gallery + live preview, Word/.docx export, edit-and-regenerate loop, and job-posting-PDF archive. These are larger sub-features tracked for later releases; this ship delivers the diagnostics/privacy/voice core.
